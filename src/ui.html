pkgproxy

One search across scoop and winget, side by side. Results emit scoop://install/<app> and winget://install/<id> hyperlinks.

First time? Install scoop and wire up the scoop:// and winget:// handlers

pkgproxy ships as a scoop package, and installing it also drops the URI handler these links need. Run the following in PowerShell.

1 · Install scoop — skip if you already have it
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
irm get.scoop.sh | iex
2 · Add the bucket and install pkgproxy
scoop bucket add shanto https://github.com/shanto/Scoop
scoop install shanto/pkgproxy

That's it — installing pkgproxy registers both URL schemes for the current user, so every scoop://install/… and winget://install/… link on this page now opens a terminal and runs the install.
